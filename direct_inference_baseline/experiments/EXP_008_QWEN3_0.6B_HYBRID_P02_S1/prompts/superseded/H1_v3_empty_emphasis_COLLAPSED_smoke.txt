Rules that matter most (this is medical safety)

- A doctor's question or hypothesis is not a fact. Use the answer. Keep denied findings in negative_findings, not in symptoms.
- Write one item per distinct fact; do not merge facts and do not repeat a fact that is only said again.
- evidence_ids lists the id of the line that states the fact, copied exactly as printed (SEG followed by four digits). Use ONE id, or at most TWO. Never list more than two.

A value read out by a doctor or nurse is reported by that person. If you cannot tell who said it, write unknown.
- All confidence fields are null and clinical_evidence is always [].

What to write
- chief_complaint: the main reason for the visit in the patient's own words, from the patient's answer.
- symptoms: each problem the patient reports, one item each. temporality: current (still happening, also if it comes and goes), past (an earlier episode that is over) or resolved (happened during this illness and has gone). duration only when a length of time is stated. severity, onset, frequency, body_site and the three factor lists only if said. certainty uncertain when the patient hedges.
- negative_findings: each thing a speaker says is absent, one item per thing. Never from something that was not discussed.
- medical_history: past_medical_history (the patient's own conditions), surgical_history (past operations, timeframe as spoken), family_history (condition and relation; never the patient's own condition), social_history only when discussed. Never assume a social history.
- medications: one item per medicine a speaker names. dose, frequency, route (only the word oral, only when said) and indication only when said for THAT medicine, never copied from another medicine and never from what the medicine is usually for. A medicine only the doctor names is not currently_used.
- allergies: only allergies a speaker states. A medicine the patient takes is not an allergy. If allergies were not discussed, [].
- vital_signs: only measurements for which a speaker says a number; keep the whole value (a blood pressure has both numbers) and the unit as said. reported_by is the person who said it, which can be the patient. If no number is said, [].
- physical_examination: only what the clinician examined and observed. A symptom the patient reports is not an examination finding. If no examination is described, [].
- review_of_systems: only body systems explicitly said to be negative. clinical_conditions: conditions already on record that the doctor acknowledged; if unsure, [].
- clinical_assessment: each impression the doctor states, provisional or differential; never turn a possibility into a diagnosis; if the doctor states none, [].
- procedures_and_investigations: each test, scan or procedure ordered, done or discussed. indication only if the doctor gives a reason; scheduled_datetime null unless a date or time is spoken.
- clinical_actions: each instruction or plan the doctor states, one item per action (tests, referrals, medication steps, advice, when to seek urgent care, follow-up). If no plan is stated, [].
- follow_up: each follow-up visit, time_reference exactly as spoken. If none, [].
- clinical_uncertainties: only uncertainty that is actually present (unclear dose or date, conflicting statements, a missed dose, a medicine that cannot be named). A null field alone is not an uncertainty.
- encounter_metadata.primary_speakers: one entry for each distinct person_N id printed in the transcript (never a SEG id), role in lower case.
